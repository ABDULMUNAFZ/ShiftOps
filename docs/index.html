Build from source

Requirements: Node.js 22.22 or newer, pnpm 10, a stable Rust toolchain and the Tauri 2 system prerequisites for your OS.

git clone <repository-url> shiftops
cd shiftops
pnpm install
pnpm dev:desktop

First-run environment checks

On first launch ShiftOps runs these checks natively through its Rust backend and shows the raw result. A tool that is missing is reported as unavailable with the reason; nothing is assumed.

CheckHow it is performed
Operating systemCompile-time OS and architecture, plus sw_vers on macOS, /etc/os-release on Linux or ver on Windows.
Application data directoryResolves the per-user data directory and writes then deletes a probe file.
Git, Node.js, pnpm, npm, Yarn, Devin CLIFinds the executable on the PATH from your login shell, then runs it with --version.
DockerRuns docker --version, then docker info to confirm the daemon is reachable.
OS keychainWrites, reads back and deletes a probe credential.

Desktop apps started from the Dock or a launcher do not inherit your shell PATH, so ShiftOps reads it once from your login shell and adds common install locations such as /opt/homebrew/bin.

Keyboard shortcuts

  • ⌘K / Ctrl+K: command palette
  • ⌘1–⌘7: go to Overview, Repositories, Campaigns, Agent Runs, Verification, Integrations, Settings
  • ⌘B / Ctrl+B: collapse or expand the sidebar
  • ⌘J / Ctrl+J: open the Activity Centre
