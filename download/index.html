Pre-release v0.1.0 for macOS, Windows and Linux. These installers are unsigned.

Installers (v0.1.0)

macOS

  • macOS, Apple Silicon (.dmg) ShiftOps_0.1.0_aarch64.dmg
  • macOS, Intel (.dmg) ShiftOps_0.1.0_x64.dmg

Not signed or notarized. macOS Gatekeeper blocks unsigned downloads, so on macOS building from source (below) is the dependable route until signed builds exist.

Windows

  • Windows x64 installer (.exe) ShiftOps_0.1.0_x64-setup.exe
  • Windows x64 (.msi) ShiftOps_0.1.0_x64_en-US.msi

Not code-signed. Windows SmartScreen shows an “unknown publisher” warning; choose More info, then Run anyway, only if you trust this download.

Linux

  • Linux x64 (.AppImage) ShiftOps_0.1.0_amd64.AppImage
  • Debian / Ubuntu x64 (.deb) ShiftOps_0.1.0_amd64.deb

AppImage runs on most distributions (make it executable first); the .deb installs on Debian and Ubuntu.

All files and checksums are on the GitHub release page.

Build from source

  1. Install Node.js 22.22 or newer and pnpm 10.
  2. Install Rust with rustup and the Tauri 2 prerequisites for your platform.
  3. Clone the repository and run:
git clone https://github.com/ABDULMUNAFZ/ShiftOps.git
cd ShiftOps
pnpm install
pnpm dev:desktop        # development build with hot reload
pnpm build:desktop      # local installer for this machine (unsigned)

A locally built app is not quarantined, so macOS runs it without the Gatekeeper prompt that downloaded unsigned builds trigger. See the documentation for what the current build does.
